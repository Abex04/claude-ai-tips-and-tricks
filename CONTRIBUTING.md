# Contributing to Claude AI Tips & Tricks

Thanks for wanting to contribute! This repo works best when entries are consistent, practical, and actually tested. A few guidelines:

## Before you submit

- **Search first** -- check the relevant folder to make sure a similar tip doesn't already exist. If it does, consider improving it instead of duplicating it.
- **One tip per file** -- keep entries focused and scannable.
- **Test it** -- make sure the prompt/technique actually works as described before submitting.

## Where to put it

Pick the folder that best fits:

| Folder | For |
|---|---|
| 01-getting-started | Beginner-friendly basics |
| 02-prompting-techniques | Core, reusable prompting patterns |
| 03-workflows | Multi-step processes for a real task |
| 04-claude-code | Claude Code / agentic coding tips |
| 05-advanced-prompt-engineering | Deeper/expert techniques |
| 06-real-world-examples | Full worked examples |
| templates | Reusable prompt templates |

## Format for a tip

Create a new markdown file with a short, descriptive, kebab-case filename (e.g. summarize-long-documents.md), structured as:

- Title
- Problem: what situation or frustration does this solve?
- Prompt / Technique: the actual prompt, written out fully
- Why it works: a short explanation of the underlying principle
- Example (optional but encouraged): a short before/after or sample output

## Submitting

1. Fork the repo
2. Create a branch (git checkout -b add-tip-name)
3. Add your file in the right folder
4. Open a pull request with a short description of what you added

## Style notes

- Keep it practical over theoretical -- show, don't just tell.
- Write for someone trying to solve a real problem, not a textbook reader.
- No AI-generated filler -- every tip should reflect something that actually works.

Questions or ideas? Open an issue.
